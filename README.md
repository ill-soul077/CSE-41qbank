# CSE 4-1 Question Bank

An offline question browser for six subjects, with **1,517 original exam questions**, source scans, exam-style solutions and quick revision guides.

## Download and open

**All subjects:** [Download the repository ZIP](https://github.com/ill-soul077/CSE-41qbank/archive/refs/heads/main.zip), extract it, then open any HTML file inside `dist/portable/` in your browser.

**One subject:** use a download link below. If it opens as text, save it with its original `.html` filename. You can also open the file on GitHub and choose **Download raw file**.

Each HTML file works independently. No installation, server or internet connection is needed after downloading. Keep the original filenames together if you want the links between subjects to work. The files are about 16–29 MB because they contain the original question images and scan pages.

## Included

- Continuous question lists, filtered by year, section, topic and repetition.
- Lecture and slide filters for Graphics, Networks and NLP.
- Quick Review: connected topic maps, comparisons, common mistakes, revision checklists and 230 equation cards across 107 topics.
- Searchable reviews, an equation-only view and links to related practice questions.
- Done/unfinished tracking, review flags and personal-answer ordering.
- Personal answers with Markdown, LaTeX, tables and pasted screenshots.
- Embedded JSON/Markdown exports and complete backups.

Personal notes and progress are stored locally in your browser. Export a backup before moving computers or clearing browser storage. This public edition contains no saved personal notes.

Solutions are study aids and can contain errors. Check the original scan and your course material; source-limited or ambiguous exercises are identified where known.

This repository contains only the six standalone HTML files and the download guide. Editable sources, temporary outputs, local notes and development files are excluded through `.gitignore`.
